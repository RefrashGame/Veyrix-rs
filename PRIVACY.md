# Политика конфиденциальности Veyrix-rs

Действует с 26 ноября 2026 года. Относится к программе Veyrix-rs для Windows и к Telegram-боту
[@BugReportVeyrixbot](https://t.me/BugReportVeyrixbot), который принимает отчёты о проблемах.

## Коротко

- Veyrix-rs работает на вашем компьютере. У программы нет своего сервера, аккаунтов и рекламы, она **не собирает
  статистику** и ничего не отправляет «в фоне» о вас или ваших сайтах.
- Данные уходят разработчику **только когда вы сами отправляете отчёт** через «Сообщить о проблеме».
- Остальные обращения в сеть — это работа функций, которые вы включаете: проверка обновлений, DNS-over-HTTPS,
  WARP, Telegram-прокси. Ниже — что, куда и зачем.

## Что остаётся на компьютере

Всё хранится в папке программы (`%LOCALAPPDATA%\Veyrix-rs` при установке или папка архива) и никуда не передаётся:

- `data\settings.json` — ваши настройки;
- `data\tuning.txt` — какие приёмы обхода подошли каким сайтам (только имена сайтов и названия приёмов);
- `data\dns-backup.txt` — исходные настройки DNS, если вы меняли DNS Windows через программу;
- `data\warp\` — ключи и профиль бесплатного аккаунта WARP, если вы его регистрировали;
- журнал событий в окне — только в памяти, пропадает при закрытии программы.

Удалить эти данные — удалить программу («Установленные приложения») или папку `data`.

## Что и куда отправляется

| Когда | Куда | Что передаётся |
|---|---|---|
| Вы отправляете «Сообщить о проблеме» | Telegram, бот @BugReportVeyrixbot → чат разработчика | Ваше описание, приложенные снимки экрана, ник Telegram для ответа (если указали), версия программы |
| Запуск программы и «Проверить обновления» | GitHub (api.github.com) | Обычный запрос списка релизов; GitHub видит ваш IP-адрес |
| «Обновить» | GitHub (страница релизов) | Скачивание установщика; GitHub видит ваш IP-адрес |
| Включён DNS-over-HTTPS | Выбранный сервер: Cloudflare, Google или Quad9 | Имена сайтов, которые вы открываете, — вместо DNS провайдера |
| Регистрация и работа WARP | Cloudflare (api.cloudflareclient.com, сеть WARP) | Создание бесплатного аккаунта WARP; затем через WARP идут только соединения с адресами, заблокированными по IP. Условия Cloudflare: https://www.cloudflare.com/application/terms/ |
| Свой SOCKS5-прокси | Указанный вами прокси | Соединения с адресами, заблокированными по IP |
| Telegram-прокси | Серверы Telegram; при включённом резерве — домены Cloudflare (список Flowseal) | Трафик Telegram Desktop; он зашифрован самим Telegram, посредник видит только факт подключения |
| Замена DNS Windows | Серверы Яндекса 77.88.8.8 и 77.88.8.1 | После замены Windows спрашивает у них адреса всех сайтов |

Программа не читает содержимое ваших соединений: обход меняет только первые служебные пакеты, а сайты и так
защищены HTTPS.

## Отчёты о проблемах

- **Что попадает в отчёт:** только то, что вы ввели и приложили, и номер версии программы. Снимки экрана могут
  содержать личное — проверьте их перед отправкой.
- **Кто видит:** разработчик Veyrix-rs в закрытом Telegram-чате. Отчёты не публикуются и никому не передаются.
- **Зачем:** найти и исправить ошибку, ответить вам, если вы оставили ник.
- **Сколько хранится:** пока нужно для исправления, затем сообщение удаляется. Telegram хранит переписку по своим
  правилам: https://telegram.org/privacy
- **Удалить отчёт:** напишите в Telegram боту или по нику из ответа — отчёт удалят.

## Telegram-бот @BugReportVeyrixbot

Бот только доставляет отчёты из программы разработчику. Он не отвечает на сообщения, не собирает данные о
пользователях Telegram и не рассылает сообщений. Если вы оставили ник, разработчик может написать вам сам.

## Дети

Программа не предназначена для сбора данных детей; не отправляйте в отчётах чужие личные данные.
