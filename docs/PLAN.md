# Veyrix-rs — план

Обход DPI-блокировок на этом компьютере, без своего сервера. Rust; интерфейс — Tauri.
Перехват пакетов — драйвер WinDivert (готовый, подписанный); всё остальное своё.

Чего локальный подход не может: сайт, заблокированный по IP, открывается только через посредника
(например, Cloudflare, как в Telegram-прокси Veyrix). Вместо «100 %» цель — самовосстановление:
программа сама замечает сбой для сайта и подбирает другой приём.

## Этапы

1. **Каркас** — workspace `vx-core` (логика без драйвера), `vx-divert` (обёртка WinDivert), `vx` (консоль), CI.
2. **Перехват и разбор** — IPv4/IPv6, TCP/UDP; TLS ClientHello (SNI), HTTP Host, QUIC Initial;
   консольный режим `vx sniff`: пакеты проходят без изменений, в журнал пишутся сайты.
3. **Приёмы обхода** — разрезание TLS (по TLS-записям и TCP-сегментам), перестановка частей, фейки,
   не доходящие до сервера (TTL, контрольная сумма, seq), перекрытие (seqovl), фейки QUIC.
   **Голос Discord** — отдельная галочка, по умолчанию выключена: у провайдера владельца фейки перед голосом
   ломали подключение («Нет маршрута»), голос там не блокируется. Включать там, где голос режут.
   Проверено у владельца 2026-11-23 (без VPN): YouTube, запуск Discord, голос и демонстрация экрана работают
   со всеми вариантами — по умолчанию; `--quic drop`; `--fooling ttl=4`; `--fooling badsum --split host`;
   без фейков (`--no-fake --split 1,midsld`) Discord запускается заметно дольше. `--discord-voice` не понадобился.
4. **DNS-over-HTTPS** — провайдер не может подменить адреса. Перехват UDP 53, ответ от DoH (WinHTTP, HTTP/2)
   подставляется входящим пакетом; при сбое — обычный DNS. Системные настройки не меняются.
   shortcut: нет кэша (каждый запрос — к DoH; Windows и браузеры кэшируют сами), DNS по TCP 53 не перехватывается.
   Проверено у владельца 2026-11-23: `nslookup youtube.com 192.0.2.1` (несуществующий сервер) при `vx run --doh
   cloudflare` получает адреса — ответ подставлен из DoH; YouTube и Discord работают.
5. **Автоподбор и самовосстановление** — проверка сайта, перебор приёмов, запоминание рабочего для сайта,
   смена при сбоях.
6. **Интерфейс на Tauri** — обзор, сайты, диагностика, журнал, настройки; трей.
7. **Telegram-прокси** с резервом через Cloudflare (перенос из Veyrix), автообновление, релиз.
