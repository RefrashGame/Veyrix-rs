# Канал «Veyrix-rs · Обновления»

Тексты для оформления канала и постов о выпусках. Посты публикует отдельный бот-публикатор
(не @BugReportVeyrixbot — тот только доставляет отчёты), его токен хранится вне git.

## Оформление

- **Название:** Veyrix-rs · Обновления
- **Аватар:** `app/src-tauri/icons/icon.png` (щит с «V»)
- **Описание (до 255 символов):**

  🛡 Veyrix-rs — обход DPI-блокировок для Windows без VPN и своего сервера. Новые версии, что изменилось и как
  обновиться. Ошибки — через «Сообщить о проблеме» в программе.

## Первый пост (закрепить)

```
🛡 Veyrix-rs

Обход блокировок YouTube, Discord и других сайтов прямо на вашем компьютере — без VPN и без своего сервера.

✅ автоподбор приёма для каждого сайта
✅ обход блокировки по IP: другой адрес Cloudflare, свой прокси или встроенный WARP
✅ Telegram-прокси, DNS-over-HTTPS, мини-режим
✅ обновление из самой программы

⬇️ Скачать: https://github.com/RefrashGame/Veyrix-rs/releases
🔒 Конфиденциальность: https://github.com/RefrashGame/Veyrix-rs/blob/main/PRIVACY.md
🐞 Нашли ошибку — «Сообщить о проблеме» в программе.
```
