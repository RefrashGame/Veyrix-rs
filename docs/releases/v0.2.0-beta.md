Бета-версия: новое ещё не проверено у пользователей с блокировкой по IP. Стабильная версия — 0.1.0.

**Новое**
- **Обход блокировки по IP.** Если до адреса сайта не доходят даже пакеты подключения, Veyrix замечает это
  (нет ответа дольше 2 с) и уводит соединения с этим адресом в обход. Способ — в «Настройках» → «Если сайт
  заблокирован по IP-адресу»:
  - **Другой адрес Cloudflare** — на этом компьютере, без посредников; для сайтов за Cloudflare (Discord и др.);
  - **Свой SOCKS5-прокси** — для любых сайтов, адрес прокси указывается в настройках;
  - **Cloudflare WARP** — для любых сайтов; WARP нужно установить самим, включить режим прокси
    (`warp-cli mode proxy`) и подключиться (`warp-cli connect`).

  Для прокси и WARP при запуске обхода добавляется правило брандмауэра Windows «Veyrix-rs: обход блокировки
  по IP» (окно спрашивает согласие при выборе режима), при остановке оно удаляется.
- **Автоподбор пробует и «без приёмов».** Если сайт не открывается ни с одним приёмом, автоподбор переходит на
  прямое соединение и запоминает это — помогает там, где приёмы сами ломают сайт.
- **Консольная версия `vx.exe` убрана** — всё делается в окне.
- `tools\veyrix-check.cmd` в исходниках — проверка YouTube и Discord для разбора проблем (только читает систему).

**Ограничения беты**
Только IPv4 и порт 443; адреса Google (видео YouTube) не заменяются; первое соединение к новому заблокированному
адресу ждёт около 3 с; режим WARP не проверялся.

**Установка**
Скачайте `Veyrix-rs-0.2.0-beta-x64.zip`, сверьте SHA256 с `SHA256SUMS.txt`, распакуйте в свою папку (не в
`Program Files`) и запустите `veyrix.exe` с правами администратора. Обновление с 0.1.0: выйдите из Veyrix через
трей и замените файлы, папку `data\` оставьте — в ней настройки.

**Microsoft Defender** может удалить WinDivert из архива как «Misleading:Win32/Malgent» — так он реагирует на
перехватчики пакетов. Если файлы в `engine\` пропали: сверьте SHA256 архива, добавьте папку Veyrix-rs в
исключения Defender и распакуйте заново — решение за вами.
