Первый выпуск Veyrix-rs — обход DPI-блокировок на этом компьютере, без своего сервера и VPN.

**Что умеет**
- Обход DPI: фейковые пакеты, разрезание и перестановка TLS, режимы QUIC (фейк, отбросить, не трогать).
- Автоподбор: для каждого сайта свой приём; если сайт перестал открываться — программа сама пробует следующий.
- DNS через DNS-over-HTTPS (Cloudflare, Google, Quad9) без изменения настроек Windows.
- Telegram-прокси на 127.0.0.1: веб-вход Telegram, резерв через Cloudflare, прямое подключение.
- Замена DNS Windows на Яндекс с откатом к исходным настройкам.
- Окно: карта сервиса по живым данным, мини-режим, журнал, диагностика, трей, автозапуск с Windows.

**Установка**
Скачайте `Veyrix-rs-0.1.0-x64.zip`, сверьте SHA256 с `SHA256SUMS.txt`, распакуйте в свою папку (не в
`Program Files`) и запустите `veyrix.exe` с правами администратора — они нужны драйверу WinDivert.
Windows 10/11 x64.
