Бета-версия. Стабильная версия — 0.1.0.

**Новое**
- **Установщик.** `Veyrix-rs-0.2.1-beta-x64-setup.exe` ставит программу для текущего пользователя (без прав
  администратора) в `%LOCALAPPDATA%\Veyrix-rs`, с ярлыком в «Пуске» и удалением через «Установленные
  приложения». Архив zip остаётся для тех, кто не хочет устанавливать.
- **WARP внутри Veyrix.** Вкладка «WARP»: один раз «Зарегистрировать» (бесплатный аккаунт Cloudflare WARP),
  дальше Veyrix сам включает WARP вместе с обходом, если в настройках выбрано «Через WARP». Ставить
  отдельное приложение не нужно: внутри — открытые программы wgcf и wireproxy. Через WARP идут только
  соединения с адресами, заблокированными по IP.
- **Карта на «Обзоре»:** Компьютер → Путь (Veyrix, WARP, SOCKS5) → Как перенаправляется → Сервисы, отдельно —
  «Блок по IP».
- **Окно перетаскивается за любое пустое место**, а не только за заголовок.
- **Под настройками — «Как настроить»:** что менять, если видео не идёт, сайт не открывается, блокировка по IP и т. д.

**Ограничения беты**
Провайдер может блокировать сам WARP (протокол WireGuard) — тогда «Проверить» во вкладке WARP не пройдёт;
выберите для блокировок по IP свой SOCKS5-прокси или «Другой адрес Cloudflare». Обход по IP — только IPv4 и
порт 443.

**Microsoft Defender** может удалить WinDivert (и, возможно, программы WARP) как «потенциально нежелательные» — так
он реагирует на перехватчики пакетов и VPN-инструменты. Если файлы в `engine\` пропали: сверьте SHA256 с
`SHA256SUMS.txt`, добавьте папку Veyrix-rs в исключения Defender и установите заново — решение за вами.

В пакете без изменений: WinDivert 2.2.2 (basil00, LGPLv3 или GPLv2), wgcf 2.3.1 (ViRb3, MIT), wireproxy 1.1.3
(ISC) — тексты лицензий в `licenses\`, ссылки на исходники — в `THIRD-PARTY-LICENSES.md`.
