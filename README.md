# Veyrix-rs

Обход DPI-блокировок на этом компьютере, без своего сервера. Rust, перехват пакетов через драйвер WinDivert.
Этапы — `docs/PLAN.md`, сборка — `docs/DEVELOPMENT.md`. Лицензия — GPL-3.0 (`LICENSE`),
сторонние компоненты — `THIRD-PARTY-LICENSES.md`, конфиденциальность — `PRIVACY.md` (программа не собирает статистику;
данные уходят разработчику только в отчёте, который вы отправляете сами).

## Установка

**Установщик (проще).** Скачайте `Veyrix-rs-<версия>-x64-setup.exe` со страницы
[релизов](https://github.com/RefrashGame/Veyrix-rs/releases), при желании сверьте SHA256 с `SHA256SUMS.txt`
(`Get-FileHash .\Veyrix-rs-*-setup.exe`) и запустите. Права администратора для установки не нужны: программа
ставится для текущего пользователя в `%LOCALAPPDATA%\Veyrix-rs`, появляется в меню «Пуск» и в «Установленных
приложениях» (там же удаление). Обновление — запустить установщик новой версии; настройки в `data\` сохраняются.

**Без установки — архив.**
1. Скачайте `Veyrix-rs-<версия>-x64.zip` и сверьте SHA256 с `SHA256SUMS.txt`.
2. Распакуйте в свою папку, например `C:\Users\<имя>\Veyrix-rs` — программа пишет настройки в `data\` рядом
   с собой, поэтому не в `Program Files`.

В обоих случаях `veyrix.exe` при запуске просит права администратора: драйверу WinDivert они нужны для перехвата
пакетов. Нужна Windows 10/11 x64.

**Microsoft Defender** может удалить официальный WinDivert из архива как «Misleading:Win32/Malgent» — так он
реагирует на перехватчики пакетов, а не на вирус. Если `engine\WinDivert64.sys` или `engine\WinDivert.dll` пропал,
решите сами, доверяете ли вы файлу: сверьте SHA256 архива, затем добавьте папку Veyrix-rs в исключения Defender
(Безопасность Windows → Защита от вирусов и угроз → Исключения) и распакуйте архив заново.

Всё, что меняет трафик или систему, включается только вами: обход — кнопкой, DNS Windows — с подтверждением и
откатом, автозапуск — переключателем в настройках. Остановка обхода сразу возвращает трафик как без программы.

## Что внутри

`veyrix.exe`: обход DPI (фейки, разрезание, перестановка, режимы QUIC) с автоподбором приёма для каждого сайта,
DNS через DNS-over-HTTPS, Telegram-прокси, обход блокировки по IP (другой адрес Cloudflare, свой SOCKS5-прокси
или встроенный WARP — на выбор в настройках, WARP настраивается во вкладке «WARP»); карта сервиса (какие сайты через какие модули идут), мини-режим,
журнал, диагностика, DNS Windows, настройки; крестик прячет окно в трей.

Сборка из исходников — `docs/DEVELOPMENT.md`; выпуск — тег `vX.Y.Z` (workflow `release.yml` собирает установщик, архив и
черновик релиза с описанием из `docs/releases/vX.Y.Z.md`).
