# Veyrix-rs

Обход DPI-блокировок на этом компьютере, без своего сервера. Rust, перехват пакетов через драйвер WinDivert.
Этапы — `docs/PLAN.md`, сборка — `docs/DEVELOPMENT.md`. Лицензия — GPL-3.0 (`LICENSE`),
сторонние компоненты — `THIRD-PARTY-LICENSES.md`.

## Установка

1. Скачайте `Veyrix-rs-<версия>-x64.zip` со страницы [релизов](https://github.com/RefrashGame/Veyrix-rs/releases)
   и сверьте SHA256 с `SHA256SUMS.txt`: `Get-FileHash .\Veyrix-rs-*.zip`.
2. Распакуйте в свою папку, например `C:\Users\<имя>\Veyrix-rs` — программа пишет настройки в `data\` рядом
   с собой, поэтому не в `Program Files`.
3. Запустите `veyrix.exe` и подтвердите запрос прав администратора: драйверу WinDivert они нужны для перехвата
   пакетов. Нужна Windows 10/11 x64 (WebView2 в них уже есть).

**Microsoft Defender** может удалить официальный WinDivert из архива как «Misleading:Win32/Malgent» — так он
реагирует на перехватчики пакетов, а не на вирус. Если `engine\WinDivert64.sys` или `engine\WinDivert.dll` пропал,
решите сами, доверяете ли вы файлу: сверьте SHA256 архива, затем добавьте папку Veyrix-rs в исключения Defender
(Безопасность Windows → Защита от вирусов и угроз → Исключения) и распакуйте архив заново.

Всё, что меняет трафик или систему, включается только вами: обход — кнопкой, DNS Windows — с подтверждением и
откатом, автозапуск — переключателем в настройках. Остановка обхода сразу возвращает трафик как без программы.

## Что внутри

Окно `veyrix.exe`: карта сервиса (какие сайты через какие модули идут), мини-режим, журнал, Telegram-прокси,
диагностика, DNS Windows, настройки; крестик прячет окно в трей.

Консоль `vx.exe`: `vx sniff` — наблюдение; `vx run` — обход (фейки, разрезание, перестановка, QUIC);
`--auto` — свой приём для каждого сайта с самовосстановлением; `--doh` — DNS через DNS-over-HTTPS;
`vx diag` — диагностика; `vx tg` — Telegram-прокси.

Сборка из исходников — `docs/DEVELOPMENT.md`; выпуск — тег `vX.Y.Z` (workflow `release.yml` собирает пакет и
черновик релиза с описанием из `docs/releases/vX.Y.Z.md`).
